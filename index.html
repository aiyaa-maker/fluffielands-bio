วิธีการสั่งซื้อสินค้าไทย-ต่างประเทศ

ขั้นตอนการสั่งซื้อง่ายๆ ในไม่กี่สเต็ป

🇹🇭 วิธีการสั่งซื้อสินค้าไทย
  1. •
    เลือกสินค้า : เลือก Sticker / Theme / Emoji / Melody ที่ต้องการ
  2. •
    ส่งรูปหรือลิงก์ : ส่งรูป หรือ คัดลอกลิงก์ลายที่ต้องการ
  3. •
    แจ้งข้อมูลผู้รับ : แจ้ง LINE ID / QR Code / เบอร์โทรศัพท์ของผู้รับ (ค้นหาทางเบอร์รบกวนแจ้งด้วยนะคะ)
  4. •
    ชำระเงิน : ชำระเงินเรียบร้อยแล้ว รอรับสินค้าได้เลย
🌐 วิธีการสั่งซื้อสินค้าต่างประเทศ
  1. •
    ค้นหาเว็บไซต์ : ค้นหาคำว่า yabeline บนหน้าเว็บไซต์ที่สะดวก 🌐 เว็บดูสินค้าต่างประเทศ CLICK (yabeline.tw)
  2. •
    เลือกสินค้า : เลือกประเภทสินค้า และเลือกลายที่ต้องการ
  3. •
    แชร์ลิงก์ : กดคัดลอกหรือแชร์ลิงก์ลายที่ต้องการสั่งซื้อ
  4. •
    แจ้งข้อมูลผู้รับ : แจ้งข้อมูลผู้รับ (LINE ID หรือ QR Code) ❌ งดแชร์ผู้ติดต่อหรือค้นหาทางเบอร์โทร ❌
  5. •
    ชำระเงิน : ชำระเงินเรียบร้อยแล้ว รอรับสินค้าได้เลย
